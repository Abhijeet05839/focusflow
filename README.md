 # 🚀 FocusFlow

FocusFlow is a productivity-focused web application designed to help users stay organized, eliminate distractions, and maximize efficiency. It provides a clean and distraction-free workspace to improve focus and get more done.

---

## 🌟 Features

- 📝 Task Management (To-Do List)
- ⏱️ Focus Timer (Pomodoro Style)
- 📊 Clean & Minimal UI
- ⚡ Fast and Responsive Design
- 📱 Works on all devices

---

## 🛠️ Tech Stack

- HTML5  
- CSS3  
- JavaScript (Vanilla JS)
